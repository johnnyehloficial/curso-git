Git Multi-Dimensional Learning Platform

Aprende conceptos fundamentales, experimenta en el laboratorio y domina el trabajo en paralelo.

Módulo 1 La Fundación y el "Guardado" Local

Concepto clave: El código viaja por tres estados locales antes de consolidarse: el directorio de trabajo, el área de preparación (Staging Area) y el Repositorio Local.

Laboratorio Práctico:

  • Inicializa tu carpeta del proyecto:
    • git init
  • Crea un archivo local e incorpóralo a la zona de confirmación, luego haz la instantánea de respaldo:
    • git add index.html && git commit -m "feat: setup estructura inicial"
Módulo 2 La Nube y la Descentralización

Concepto clave: Tu repositorio local es completamente independiente de la nube. Vincular un servidor remoto sirve como respaldo masivo y para cooperar con terceros de forma distribuida.

Laboratorio Práctico:

  • Descarga un proyecto colaborativo entero desde un servidor central (GitHub/GitLab) a tu entorno de trabajo:
    • git clone https://github.com/usuario/repositorio.git
Módulo 3 Trabajo en Paralelo (Features y Ramas)

Concepto clave: Las ramas (*Branches*) abren líneas de tiempo independientes. Te permiten escribir código experimental de una funcionalidad sin alterar la estabilidad de la rama principal de producción.

Laboratorio Práctico:

  • Crea una rama paralela e intégrate a ella de forma simultánea para iniciar el desarrollo aislado:
    • git checkout -b feature/nueva-interfaz
Módulo 4 Resolución de Conflictos e Integración

Concepto clave: La integración (*Merge*) unifica los universos de dos ramas. Si tú y otro miembro del equipo modifican exactamente la misma línea del mismo archivo, Git detendrá el proceso exigiendo resolución manual.

Laboratorio Práctico:

  • Regresa a la rama principal y atrae los cambios terminados de tu feature para consolidar el match:
    • git checkout main && git merge feature/nueva-interfaz
Módulo 5 Viajes en el Tiempo (La Reversa)

Concepto clave: Los errores ocurren. Git te da la habilidad de deshacer modificaciones locales o descartar commits problemáticos regresando de forma segura al pasado.

Laboratorio Práctico:

  • Borra el historial destructivo y fuerza tu espacio de trabajo local a alinearse con un commit seguro anterior:
    • git reset --hard HEAD~1
